# Gymnast - Gym & Fitness Center

A responsive gym and fitness center website built with HTML and CSS.

## Features

- Responsive gym landing page
- Hero section with call-to-action
- Body building and muscle building sections
- About / experience section
- Gym benefits and features
- Classes and team sections
- Testimonials
- Blog section
- Footer with contact information
- Font Awesome icons
- Local image assets

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. No server or database is required.

## GitHub Pages

This project can be hosted directly with GitHub Pages because `index.html` is the main entry file.

### Upload to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/gymnast-gym-website.git
git push -u origin main
```

## Notes

The page uses Font Awesome from its CDN and therefore needs an internet connection for the icon library. All main website images are included in the repository.
